yAI Code

A coding agent for your terminal that uses the same models as this site. It works on the files in the folder you start it from, and asks before it edits a file or runs a command.

  1. Install Node.js 18 or newer from nodejs.org. Check it with:
    node --version
  2. Download yAI and install the yai command (once):
    git clone https://github.com/yousefk07/yAI.git
    cd yAI && npm link
  3. Open your project and start it:
    cd path/to/your/project
    yai
  4. Sign in with the same username and password you use here.

Good to know

  • Shift+Tab switches between asking first, accepting edits, and plan (read-only).
  • /model picks a model, /help lists every command, Esc stops yAI.
  • /image and /video make media into your project, /undo reverts the last edit, /theme changes the colours.
  • @file attaches a file. yai -c continues the last conversation in a folder.
  • yai -p "question" answers once without changing anything.
  • /bench scores a model on six coding tasks, /mcp add connects an MCP server, and yAI can search the web and keep dev servers running in the background (/tasks).
  • /clone rebuilds a page from a screenshot, /resume picks an earlier conversation, and the status line shows what yAI Ultra has cost.
  • yai remote takes tasks from your phone (Run on your PC). In VS Code, install vscode/yai-code.vsix from the yAI folder for a side panel with diffs.
